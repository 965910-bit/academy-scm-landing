# Академия SCM — прототип платформы

Новый независимый раздел `/academy/`. Существующие страницы и старая система входа не заменяются. Внешние библиотеки, CDN и шрифты не нужны.

## Запуск

Из корня репозитория: `python3 -m http.server 4173 --bind 0.0.0.0`, затем `/academy/`.

Кнопка «Личный кабинет» позволяет выбрать демо-роль без пароля:
- **Абитуриент:** выбор доступного направления, создание заявки, маршрут поступления, демонстрационные записи документов, сообщения.
- **Преподаватель:** учебная группа, изменение ведомости, создание заданий, сообщения.
- **Администратор:** семь направлений, публикация и допуски, изменение статусов заявок, сообщения, экспорт и сброс.

Это **не авторизация**. Все роли работают с одним набором данных в `localStorage` (`scm-academy-demo-v1`) в пределах текущего браузера и origin. Другие устройства не увидят изменений. Сообщения общие для демо-ролей, а не приватная переписка. Файлы не загружаются, сохраняются только названия демо-записей. Не вводить реальные персональные данные.

## Семь направлений

1. ВО: 38.03.02 / 38.04.02 «Менеджмент» (планируемые профили SCM).
2. MBA / Master in SCM (не приравнивается к магистратуре).
3. Двухдневные интенсивы.
4. Профессиональная переподготовка (ФИС ФРДО — реестр, не квалификация).
5. Подготовка к международным программам (без заявления партнёрств ASCM, FIATA, MIT).
6. Внутренняя академия предприятия.
7. Семинары и открытые разборы.

Все направления по умолчанию опубликованы как планируемые. Приём закрыт. Для открытия демо-приёма в панели администратора необходимы **все** условия: публикация, отметка проверки, текст оснований и дата проверки не в будущем. Снятие публикации или проверки с включённым приёмом отклоняется с объяснением: сначала отключите приём. Это намеренно строгий интерфейс, не юридическая проверка документов. Лицензия, аккредитация и международное партнёрство — разные основания. Само включение галочки не даёт никаких прав.

Цены, расписание, биографии преподавателей, реквизиты юридического лица и лицензий не выдуманы. Их нужно утвердить перед реальным запуском. Стоимость из пожеланий — ориентир рынка, не действующий прайс академии.

## До промышленного запуска

- Серверная аутентификация, восстановление доступа, проверка email, MFA для администраторов.
- Серверные роли и разграничение по пользователю, организации, группе; журнал действий. Нельзя доверять клиентским галочкам.
- База данных: пользователи/роли, направления/программы, основания/сроки действия, потоки, заявки/история статусов, зачисления, задания/попытки/оценки, сообщения.
- Защищённое файловое хранилище, антивирусная проверка, ограниченные ссылки, сроки хранения и удаления.
- Согласия и политика обработки персональных данных, проверка применимых требований 152-ФЗ и локализации; договоры и оферты.
- Полноценная CMS: планы занятий, расписание, материалы, обратная связь, уведомления.
- Юридическая проверка права на каждый формат, выдачу документов и упоминание партнёрств. Публичный набор включается только сервером после проверки оснований.
- Отдельная интеграция с ФИС ФРДО при наличии оснований; галочка не является отправкой в реестр.
- Безопасные платежи и чеки, резервное копирование, мониторинг, доступность и нагрузочное тестирование.

Старая `auth-system.js` также содержит клиентские демонстрационные пароли и не используется этим разделом. Не применять её для защиты реальных кабинетов.

## Проверки

```sh
cd academy
npm ci
npm test
```

13 DOM-тестов (jsdom): каталог/фильтры, условия допуска, будущая дата, полный путь заявки, скрытие направления, ведомость/задания, демо-документы, экранирование сообщений, закрытый приём и сброс; внутренняя навигация подвала, вход по ролевым карточкам и возврат из кабинета к FAQ. Это функциональные DOM-тесты, не проверка вёрстки в реальном браузере.

## Визуальная система

Единый цветной интерфейс: фиолетовая основа, оранжевые и бирюзовые акценты, индивидуальные цвета направлений, собственная SVG-иллюстрация цепи поставок. Главная, диалоги и кабинеты используют одну визуальную систему. Подвал содержит только внутреннюю навигацию платформы; перехода на старый лендинг нет. Добавлены карточки входа по ролям и FAQ. Анимация иллюстрации отключается при `prefers-reduced-motion`. Внешних ресурсов для оформления не требуется.
