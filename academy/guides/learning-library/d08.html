Условие готовности

Для каждого результата обучения: объяснение → пример → самостоятельная практика → проверка → обоснованный ответ или рубрика. Источники проверяются по дате, редакции и правам использования. Требования к практике, преподавателям и допуску определяются отдельно для каждой программы. Пробелы нельзя закрывать копированием одного общего текста.
