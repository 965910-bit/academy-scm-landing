# Запуск сайта с авторизацией

Нужен Node.js 22.13+ с SQLite. Из корня репозитория: `npm start`.
Сайт и `/api/` обслуживаются одним сервером на порту 4173. Для предпросмотра открывайте именно этот сервер, а не статический файловый сервер.

На рабочем сервере:

1. Задайте `PUBLIC_ORIGIN=https://scm-news.online`, `DATA_DIR` с постоянным диском и правами только для пользователя приложения, `PORT=4173`.
2. Запускайте `npm start` через менеджер процессов с автоматическим перезапуском.
3. Настройте HTTPS и проксирование всего домена на этот процесс (пример в `nginx.conf.example`). Не заменяйте ответы `/api/` страницей index.html.
4. Первого администратора создайте командой `npm run bootstrap -- "Фамилия Имя Отчество"`. Команда показывает сгенерированный пароль один раз. Существующий администратор не перезаписывается.
5. Проверьте `/api/me`: без входа ожидается JSON с HTTP 401, не HTML. После входа `/api/state` и `/api/users` администратора должны отвечать HTTP 200.

GitHub Pages и другой чисто статический хостинг не запускают этот API. Обновление файлов сайта не создаёт учётную запись на рабочем сервере. Локальная база среды разработки не является рабочей базой; секреты и SQLite не коммитьте. Перенос выполняется отдельно с резервной копией.
