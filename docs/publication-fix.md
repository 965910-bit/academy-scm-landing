# Исправление входа и обновления опубликованной платформы

## Подтверждённая причина

GitHub Pages публикует `main`, каталог `/`. Последняя успешная публикация до исправления — commit `f58eafdb6f4b6a2484fb92e11dc7264b80eb327a` (merge PR #25). Через публичный адрес прочитаны:

- `https://scm-news.online/` — старый лендинг с отдельной навигацией, ссылкой «Запросить демо-доступ» на `#` и ссылками на старый сайт.
- `https://scm-news.online/academy/` — новая платформа.
- `https://scm-news.online/academy/assembly.js` — опубликованный модуль 28 разделов.

Следовательно, отсутствие новой платформы на главном входе — не неудачный merge и не доказанная проблема service worker. Главная страница просто не была заменена. Возможное устаревание отдельных файлов браузера было дополнительным риском, не установленной причиной конкретного пользовательского сеанса.

Настройки Pages показывали `https_enforced: false`. HTTP может лишить приложение требуемых secure-context API, включая `crypto.randomUUID`. Наблюдение ошибки непосредственно в браузере владельца недоступно, поэтому это дополнительный воспроизводимый риск, а не утверждение о причине его конкретной ошибки.

## Исправления

1. Корневой `index.html` переводит на `/academy/`, сохраняя параметры и фрагмент. Есть переход без JS через meta refresh и обычная ссылка. Дублирующий старый лендинг убран.
2. Для production-доменов `scm-news.online` / `www.scm-news.online` добавлен переход на HTTPS. Preview и localhost на production не перенаправляются. Изменить настройку Pages через PUT API текущему GitHub-подключению не позволено (403); настройка на стороне Pages не объявляется изменённой.
3. Все JS-модули и основной CSS загружаются с единым `?v=assembly-20261119-21`. Это предотвращает использование старых браузерных URL файлов для данной поставки.
4. Вверху показан номер сборки и кнопка «Обновить файлы». Она обновляет установленный worker и перезагружает HTML по новому URL, не очищая localStorage, профили, записи и вложения. Временные параметры обновления удаляются из адреса после загрузки.
5. В основной навигации есть прямая ссылка «Сборка · 28 разделов». После входа открывается именно запрошенная мастерская, а не только список учётных записей.
6. Оффлайн-пакет v21 включает `release.js`. Worker умеет находить публичные ресурсы с точным токеном версии в каноническом кэше; произвольные query-параметры не перехватываются.
