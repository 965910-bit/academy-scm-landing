## Проверено

- python3 scripts/build-project-dossier.py — сборка HTML, вложенных исходников, ZIP и расчётов.
- python3 scripts/test-project-dossier.py — 9 проверок: мост прибыли, выручка, безубыточность, отрицательный вклад, наценка/маржа, целостность ZIP, ссылки, атрибуция и экранирование HTML.
- npm ci в корне и academy — установка зафиксированных зависимостей; аудит npm сообщил 0 уязвимостей на момент установки.
- npm test — 194 теста приложения прошли после установки зависимостей и расширения проверки подвала для внутренней страницы документации.
- node --check academy/release.js и academy/sw.js; git diff --check — без ошибок.

Первый запуск тестов был неполным из-за отсутствия jsdom/jose в рабочей среде. После npm ci обе зависимости установлены; это не исправление бизнес-логики. Проверка подвала ранее разрешала только якоря; теперь дополнительно разрешён ровно один существующий внутренний адрес документации. Внешний старый сайт по-прежнему не разрешён.

## Ограничения

Новые браузерные end-to-end, нагрузочный тест, проверка внешних платёжных/вебинарных провайдеров и независимый ИБ/юридический аудит этой поставкой не выполнены. Документы не меняют текущие статусы 108 требований. Подписанные приказы, поданные уведомления, действующие лицензии и производственная PostgreSQL не созданы.

Основной артефакт: /academy/guides/project-dossier/. Публикация выполняется через main; успешная доступность проверяется отдельно после деплоя. Сам этот текст не является свидетельством ещё не выполненного деплоя.

### Что здесь может пойти не так
- Локальные тесты ошибочно принимают за подтверждение доступности основного домена.
- Успешную сборку документов принимают за готовность серверной миграции.
- Условные финансовые показатели называют фактической прибылью.
