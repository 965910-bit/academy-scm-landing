# Excel: практическая лаборатория

Автор собственного материала: Герасимов Дмитрий Сергеевич. Версия библиотеки 0.11.0 от 2026-11-19.

1. Скачайте `excel-practice.xlsx`, `excel-orders.csv`, `excel-answers-template.csv` и `check-excel-results.py` в одну папку. Работайте только с вымышленными данными. Макросы, внешние подключения и учетная запись для файлов не нужны.
2. В книге прочитайте Readme. Raw — исходные десять строк; Work — рабочая копия, которую нужно очистить. Learner — пятнадцать численных результатов. Clean и Answer — открытые эталоны, не секретный экзамен.
3. Выполните восемь уроков. На Work сохраните копию, исключите O005/O006 с записью причин, удалите один полностью совпадающий повтор O003. Не удаляйте нулевой O009. Добавьте расчет суммы строки и оплаченной суммы; сверьте региональный итог. Журнал ведите на Issues, региональную таблицу заполните на Summary. Диаграмму создайте самостоятельно по региональным суммам.
4. В Learner впишите численные ответы. Значения процентных метрик записывайте процентным числом: например `8.33`, не долей `0.0833` и не строкой с `%`. Округление до двух знаков допустимо; счетчики должны быть точными. Экспортируйте только этот лист как UTF-8 CSV с заголовком `metric,value` или `metric;value`. Все 15 метрик обязательны. Если Excel экспортировал проценты или формулы текстом, исправьте формат экспорта, а не эталон.
5. Для независимого расчета: `python3 check-excel-results.py`. Для проверки своего CSV: `python3 check-excel-results.py --answers my-results.csv`. Ошибка дает ненулевой код завершения и имена проблемных метрик. Скрипт не изменяет файлы и не обращается к сети.
6. Передайте книгу, журнал преобразований, региональную таблицу/диаграмму, CSV ответов, вывод проверки и объяснение расхождения с отчетом 2900 ₽. Преподаватель просматривает формулы и смысл выводов отдельно. Повторную попытку сохраните новой версией.

## Важные границы

- Генератор проверяет структуру XLSX и сохраняет расчетные кеши, полученные Python. Файл не был пересчитан нативным Excel в среде разработки. При открытии проверьте пересчет, локаль и совместимость конкретной версии. Наличие кеша — не доказательство исполнения формулы в Excel.
- На Raw/Work числовые исходники намеренно представлены текстом: типизация — часть задания. В открытом Clean числовые поля типизированы и есть формулы. Формулы файла используют английский синтаксис OOXML; интерфейс редактора может локализовать имена и разделители.
- Автопроверка не оценивает формулы, диаграмму, самостоятельность, владение интерфейсом или полноту объяснения. Совпадающие числа можно переписать, поэтому PASS не является аттестацией.
- Ставка 5% — только учебный резерв, не налог и не обязательная комиссия. Статус paid — условие аналитического кейса, не юридическое основание признать бухгалтерскую выручку.
- Это расширенный модуль на одном кейсе, не весь Excel и не полная программа профессии. Экспертная проверка, апробация и проверка нативного интерфейса остаются открытыми.

## Что сдавать в Learner

| metric | Значение и единица |
| --- | --- |
| valid_records | Допустимые уникальные строки всех статусов |
| invalid_rows | Исходные строки, исключенные по правилам данных |
| duplicate_rows | Лишние полностью совпадающие строки после проверки допустимости |
| paid_records | Допустимые уникальные строки paid, включая нулевую |
| paid_units | Сумма units по этому же подмножеству |
| all_amount | Сумма units × price по всем допустимым уникальным строкам, ₽ |
| paid_amount | Такая же сумма только paid, ₽ |
| north_paid / south_paid | Две отдельные метрики стоимости paid по регионам, ₽ |
| weighted_price | paid_amount / paid_units, ₽/ед. |
| defect_units_percent | Дефектные единицы paid / paid_units × 100 |
| defect_rows_percent | Строки paid с дефектом / paid_records × 100 |
| reserve | Условные 5% от paid_amount, ₽, не налог |
| total_with_reserve | paid_amount + reserve, ₽ |
| report_delta | 2900 − paid_amount, ₽ |

## Человеческая приемка

Четыре критерия практики дают по 0–3 балла: исходник/очистка, формулы/агрегаты, смысл средних/долей, отчет/сверка/воспроизводимость. 0 — отсутствует или неверно; 1 — существенный пробел; 2 — небольшой пробел; 3 — полно и обоснованно. Вопросы — 12 × 2 балла; вместе с практикой максимум 36, ориентир 27 без критических ошибок. Преподаватель просит показать одну скопированную формулу, изменение ставки Settings!B2 с пересчетом, диапазоны COUNTIFS и источник исключений. Изменение ставки выполняется в отдельной копии: автопроверка эталонного кейса по-прежнему ожидает 5%. Скрипт не заменяет эти наблюдения. Исправление ошибки не стирает первую попытку.
