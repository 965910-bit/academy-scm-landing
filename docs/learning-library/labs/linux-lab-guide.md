# Linux: локальная файловая практика

Автор собственного материала: Герасимов Дмитрий Сергеевич. Версия библиотеки 0.12.0 от 2026-11-19.

## Подготовка

Скачайте `linux-lab.py` и, для последующей самопроверки, `linux-reference.sh`. Прочитайте оба файла до запуска. Нужны собственная разрешенная Linux-среда, Bash, Python3, grep, cut, sort, uniq и обычные файловые утилиты. Ничего не устанавливайте с повышенными правами ради задания. Если компонентов нет, используйте отдельно согласованную учебную среду; не меняйте производственный сервер.

Из каталога со скачанным Python-файлом:

```bash
python3 linux-lab.py --init linux-practice
cd -- linux-practice
pwd
ls -la
```

`linux-practice` — пример нового имени. Инициализатор откажется работать, если оно занято; он ничего не удаляет и не перезаписывает. Маркер `.academy-linux-lab` и `input/events.log` должны находиться внутри новой папки. Исходник содержит восемь вымышленных строк с завершающими переводами строк. Не используйте реальные журналы и секреты.

## Задание и контракт сдачи

| Путь от корня лаборатории | Требование |
| --- | --- |
| `input/events.log` | Исходник, байтовое содержимое не изменено |
| `work/events-copy.log` | Копия исходника |
| `reports/errors.log` | Только три строки, начинающиеся с `ERROR `, в исходном порядке |
| `reports/error-counts.txt` | `1 duplicate_id` и `2 missing_price`; ведущие пробелы допустимы |
| `reports/error-total.txt` | Число `3` |
| `reports/fatal.log` | Пустой результат поиска `^FATAL ` в существующем исходнике/копии |
| `reports/fatal-status.txt` | Код `1`, снятый сразу после поиска без совпадений |
| `reports/note.txt` | Непустое объяснение результатов, ограничений и режима `600` на Linux |

Также сдайте заполненный `linux-command-journal.csv` со своими командами, ожидаемым/наблюдаемым результатом и статусом. Валидатор журнал команд не исполняет и не оценивает его содержание. Устное объяснение, смысл заметки и отсутствие опасных действий оценивает преподаватель.

Сначала выполните восемь уроков самостоятельно. Для отдельной проверки, находясь в корне лаборатории:

```bash
python3 ../linux-lab.py --check .
```

Этот относительный путь предполагает ровно структуру выше. Если скрипт лежит в другом месте, укажите его действительный путь в кавычках. `--check` только читает известные файлы; он не запускает ваш shell-сценарий и не обращается к сети. Несовпадение дает ненулевой код завершения с причиной. Исходник проверяется по содержимому, а не по одной метке времени.

## Открытый эталон — после самостоятельной попытки

Ниже предполагается, что `linux-reference.sh` лежит рядом с `linux-lab.py`, на уровень выше учебной папки. Сначала прочитайте его. Он создаёт либо **перезаписывает** известные файлы внутри `work/` и `reports/`, поэтому не используйте его поверх первой попытки, которую хотите сохранить.

Создайте другую новую папку из каталога со скачанными файлами, затем:

```bash
python3 linux-lab.py --init linux-reference-practice
cd -- linux-reference-practice
bash ../linux-reference.sh
python3 ../linux-lab.py --check .
```

Проверка маркера в эталоне защищает от части случайных запусков не из того каталога, но **не является песочницей или защитой от подмены файлов**. Работайте только со своей новой папкой без параллельных изменений другими пользователями.

## Что действительно проверяется

- Сохранность источника и копии, точная выборка и численные результаты.
- Различение отсутствия совпадений и ошибки чтения по требуемому файлу статуса. Сам файл статуса можно переписать вручную, поэтому способ его получения проверяется человеком.
- Непустая заметка и режим `600` на POSIX. На другой ОС факт проверки прав явно выводится отдельно; он не означает подтвержденную эквивалентность Linux.
- Отвергаются символические ссылки на проверяемых путях, специальные файлы и файлы свыше 1 МиБ. Это локальный учебный помощник, не защищенный сервис для одновременных враждебных пользователей.

## Рубрика преподавателя

Четыре критерия по 0–3 балла: сохранность/границы, выборка/потоки/коды, конвейер/группировка, права/объяснение/передача. 0 — неверно или отсутствует; 1 — существенные пробелы; 2 — небольшой пробел; 3 — полно и обоснованно. Двенадцать контрольных вопросов дают до 24 баллов; вместе максимум 36, учебный ориентир 27 без критических ошибок. Иные безопасные команды допустимы при том же результате и правильном объяснении.

Попросите слушателя: показать `pwd` до записи; объяснить опасность одинакового пути входа/выхода; различить `grep=1` и ошибку; показать статус цепочки с/без `pipefail`; объяснить соседство повторов у `uniq`; назвать ограничения прав `600`. Нельзя выдавать PASS за квалификацию администратора или подменять понимание запуском открытого эталона. Повторную попытку сохраняйте новой папкой.

## Что осталось за пределами модуля

Установка и обновление ОС, администрирование пользователей/служб, сеть, производственная диагностика, защищенное проведение экзамена и профильная апробация. Никаких `sudo`, удаления каталогов или рекурсивного изменения системных прав в задании нет. Совместимость других оболочек и реализаций утилит требует отдельной проверки.
