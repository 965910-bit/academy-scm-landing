# Учебная база

Автор собственных материалов: Герасимов Дмитрий Сергеевич. Версия библиотеки 0.4.0 от 2026-11-19.

34 направления; 116 предварительных курсов. Для 10 курсов написаны вводные комплекты; 106 курсов пока запланированы. Отдельно написан межотраслевой материал. Итого: 11 материалов, 43 уроков, 68 открытых ответов. Полное покрытие профессий не достигнуто. Одобрено специалистом: 0. Готовых регулируемых программ: 0.

Исходники: course-packs.json, digital-packs.json, business-packs.json, foundation-data.json; лаборатории — labs/. Матрица — coverage.csv; точные счетчики — progress.json. Для каждого предметного комплекта доступен полный текст Markdown с открытыми ответами. Общий реестр дополнительных источников — learning-sources.csv (объем проверки указан отдельно).

Сборка: python3 scripts/build-learning-library.py
Проверки: python3 scripts/test-learning-library.py и python3 docs/learning-library/labs/run-digital-labs.py

Публикуемые ответы предназначены для самопроверки, не секретного экзамена. Закрытая аттестация требует серверного хранения и отдельного набора заданий; не реализована. Все материалы требуют предметной экспертизы и апробации. Внешние источники сохраняют авторство и ограничения. В цифровом блоке проверены только указанные фрагменты страниц, не полные документы.
