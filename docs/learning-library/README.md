# Учебная база: начало разработки

Автор собственных материалов: Герасимов Дмитрий Сергеевич. Версия 0.1.0 от 2026-11-19.

34 направления разложены на предварительные курсы; это не готовые программы. catalog.json и coverage.csv показывают незакрытые разделы. foundation-data.json содержит один написанный межотраслевой курс с практикой и открытыми ответами. Статус — без профильной проверки.

Сборка: python3 scripts/build-learning-library.py

Публикуемые ответы предназначены для самопроверки. Нельзя использовать их как секретный экзаменационный банк. Закрытая аттестация требует серверного хранения, разграничения прав и отдельного набора заданий; в этом изменении не реализована.

Внешние ссылки не означают проверки текущей редакции или разрешения копирования. Дальнейшая работа: полная декомпозиция профессий и ролей; проверка источников; написание каждого курса; профильная экспертиза; апробация.
