# Академия SCM

Учебная платформа, открытая библиотека и инструменты практической работы.
Единый вход: **`/academy/`**, проверка выданного документа:
**`/registry/registry.html`**.

## Вход и роли

Вход по ФИО и паролю, без самостоятельного выбора прав. Есть администратор,
приёмная комиссия, абитуриент, слушатель, преподаватель и работодатель.
Администратор создаёт все роли; приёмная комиссия — только абитуриентов
и слушателей. Временные пароли генерируются сервером, показываются один раз
и обязательно заменяются при первом входе. Администратор открывает чужой
кабинет через свою сессию, без изменения данных входа владельца.

Для серверных учётных записей нужен **Node.js-сервер**. На GitHub Pages
также доступен отдельный браузерный кабинет владельца: Герасимов Дмитрий
Сергеевич входит по ФИО без пароля; его профили и материалы сохраняются
на устройстве, а не в общей серверной базе.
Проверено на Node 22.22.3 с `node:sqlite`.

```sh
npm ci --prefix academy
DATA_DIR=/secure/academy-data node server/server.cjs bootstrap "Фамилия Имя Отчество"
PUBLIC_ORIGIN=https://ваш-домен DATA_DIR=/secure/academy-data PORT=4173 node server/server.cjs
```

Bootstrap выводит первый временный пароль только в терминал оператора.
Пароль по умолчанию отсутствует. Нельзя публиковать базу, вывод bootstrap
или файлы окружения. HTTPS обязателен: Secure-cookie включена по умолчанию.
`COOKIE_SECURE=0` предназначен только для локальных HTTP-тестов.
[Запуск и актуальные ограничения](academy/README.md).

## Возможности

- Семь подготовительных образовательных направлений с раздельными условиями
  публикации и открытия приёма; наличие галочки не подтверждает лицензию.
- Учебная библиотека, 12 вводных модулей, семь маршрутов, задания, черновики,
  ограниченная история и проверка человеком.
- Планировщик, мониторинг, разовый ICS-экспорт, лаборатория запасов и практикум
  закупочных/транспортных решений с формулами и ограничениями.
- База из десяти первоисточников, термины, учебные вопросы и открытые HTML-статьи
  `/academy/guides/`, метаданные и sitemap.
- Каталог 32 типов образовательных документов `/academy/documents/`, заготовки,
  подготовка черновиков и проект карточки слушателя.
- Проверка публичной записи о выдаче по коду: выдача/отзыв/замена/срок,
  ошибки сети и устаревший снимок. Подтверждённых публичных выдач пока нет.
- Серверные аккаунты, сессии, отдельные рабочие пространства, журнал критических
  действий с реальным ID администратора и защита от конфликтов ревизий.

## Что важно не перепутать

Учётные записи защищены сервером, но учебные профили/группы внутри прежних
модулей пока относятся к одному workspace. Полная адресная совместная работа
между реальными аккаунтами преподавателя и слушателя, общая очередь заявлений
приёмной комиссии и глобальная публикация программ требуют следующего этапа.
Старые общие браузерные данные не импортируются автоматически в чужой аккаунт.

Официальная выдача дипломов/студенческих, ЭП, государственная интеграция ФРДО,
оплата, аккредитация, партнёрства и подтверждение лицензии не заявляются.
Сертификат интерфейса или код записи не заменяет эти основания.

Офлайн-пакет **v10** содержит только публичные ресурсы. Приватные API-ответы
не кэшируются. Вход и сохранение на сервере требуют сети; несохранённый ответ
при обрыве остаётся в памяти открытой вкладки, доступен экспорт. Полноценная
приватная офлайн-очередь пока не реализована.

## Проверки

```sh
npm test --prefix academy
CHROMIUM_PATH=/path/to/chromium npm run test:browser --prefix academy
node scripts/build-guides.cjs
node scripts/build-documents.cjs
```

**74 автоматических теста** и Chromium с настоящим временным HTTP-сервером:
ФИО/пароль, первая смена, генерация, права, административный доступ, изоляция,
сохранение, выход и мобильные ширины. Это не полный аудит безопасности,
законодательства, production-хостинга или производительности.

### Что здесь может пойти не так

- Статическую публикацию примут за развёртывание сервера: без Node API кабинеты не войдут.
- Данные сохранят на временном диске: нужны постоянный DATA_DIR, резервные копии и проверка восстановления.
- Контур аккаунтов назовут завершённой LMS: организационные процессы и защищённые документы подключаются отдельно.
- Историческую документацию сочтут актуальным обещанием: новые решения и ограничения сверяются с документом 16.
